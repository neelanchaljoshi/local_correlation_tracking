Guaranteed minimum: the largest df below which an empty passband (and therefore a zero eigenfunction) is possible purely from grid alignment, for ANY cent_freq. Assumes the pipeline default of tukey_alpha=0.0 (rectangular window); if a caller opts into tukey_alpha > 0 the taper zeroes the first/last surviving bin and a larger margin is needed — see TestTukeyWindowBehavior in test_span_resolution.py.
Recommended: guaranteed minimum plus a 20% safety margin.
